# 🎓 Student Management System – Spring Boot

## 📌 About the Project

A Student Management System built using **Java 17 and Spring Boot** to develop and demonstrate practical backend development skills. The application provides RESTful APIs for managing student records through complete CRUD operations and follows a **Controller-Service-Repository architecture** for clean separation of responsibilities.

## 🛠️ Technologies & Skills

Built with **Java, Spring Boot, Spring Web, Spring Data JPA, Hibernate, MySQL, Maven, Git, GitHub, and Postman**. The project also uses **Aiven Cloud MySQL** for cloud-based database integration and includes a basic frontend for interacting with the application.

## ⚙️ Backend Implementation

The project implements **DTOs for request and response handling**, entity-to-DTO mapping, **input validation**, `ResponseEntity`, HTTP status codes, dependency injection, JPA repositories, and Hibernate for database persistence. I also implemented **global exception handling** to manage validation errors, missing resources, and runtime exceptions with consistent API responses.

## ☁️ Database & Configuration

The application is connected to a **cloud-hosted MySQL database on Aiven**. Database credentials are managed using **environment variables** rather than being hard-coded, providing a safer approach for local development and future cloud deployment.

## 🎯 What I Learned

Through this project, I gained hands-on experience in designing REST APIs, structuring a Spring Boot backend, working with DTOs and validation, handling exceptions, integrating MySQL using JPA/Hibernate, testing APIs with Postman, using Git/GitHub, and connecting an application to a cloud database.

## 🔐 Future Improvements

The next phase of the project is to implement **Spring Security, authentication, authorization, JWT, and role-based access control**, taking the application closer to a production-ready backend.
